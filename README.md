# AI-Assisted C to Python Programs
 
A small learning project containing Python versions of three C examples:
factorial calculation, Fibonacci sequence generation, and a Student record.
 
## Requirements
- Python 3.9 or newer
- A terminal or code editor
 
## Files
- `factorial.py` - calculates n! for n from 0 to 20.
- `fibonacci.py` - prints the first n Fibonacci terms (1 <= n <= 50).
- `student_record.py` - accepts and displays a student record.
 
## Run the programs
```bash
python factorial.py
python fibonacci.py
python student_record.py
```
 
Follow the on-screen prompts. Invalid values are reported instead of
being silently accepted. The factorial range is limited to match the
unsigned 64-bit range used in the sample C program.
 
## Learning Notes
The project demonstrates loops, input validation, functions, and the
Python `dataclass` as an alternative to a C `struct`.
